#### Featured projects

**[Transcript Hub](https://github.com/Ojas-suratkar/Highschool-Transcript-Depot)** — Full-stack transcript management platform with automated PDF extraction, OTP auth, and admissions review workflows. React + TypeScript, FastAPI, PostgreSQL, Terraform on GCP.

**[Inventiflow](https://github.com/Ojas-suratkar/Inventiflow)** — Full-stack inventory management app with a Node/Express backend and React + TypeScript frontend for tracking stock, orders, and suppliers.

**[Fake News Detector](https://github.com/Ojas-suratkar/fake-news-detector)** — End-to-end NLP pipeline that classifies news text as fake or real, with a CLI predictor and a Streamlit demo app.

**[Wage Gap Insights](https://github.com/Ojas-suratkar/Gender-Wage-Gap-Analysis)** — Interactive data dashboard analyzing gender pay disparities and salary-history anchoring effects, built for the LMU Datathon.

**[CareerMatrix](https://github.com/Ojas-suratkar/CareerMatrix)** — Team hackathon project matching students to careers with an ML-powered recommendation engine (Flask + scikit-learn backend).
